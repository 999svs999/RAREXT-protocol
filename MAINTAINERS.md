# Maintainers

| Name | Role | Areas |
|---|---|---|
| Project founder | Maintainer | Product, protocol, docs |

This file is intentionally small at launch. Maintainers are added through the contributor ladder described in [CONTRIBUTING.md](CONTRIBUTING.md) after sustained, reviewed contributions.

## Contact

- Code of conduct reports: contact any maintainer privately, or use GitHub's private reporting.
- Security reports: follow [SECURITY.md](SECURITY.md).
- Everything else: open an issue or an RFC.
