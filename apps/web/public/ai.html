AI lives here, not on a server

This page runs the committed model in your browser — the same numbers the published bundle was generated with — and assembles the evidence an attestation would carry. Nothing is fetched to run it, nothing is sent anywhere, and no key is involved: a signature is an identity claim, and a page has no identity. What you get is the PROOF, which anyone can recompute.

Or measure a LOSSY reconstruction

      

        Real model classes cannot be hash-compared — a quantized network, a compressed
        embedding, a neural codec regenerate differently on other hardware. That claim is a
        distance instead, and it is measured here too. The committed
        reference is read from the bundle beside this page (the mirror serves one),
        so the page cannot drift from the artifact it is measuring.
