Welcome to ApesDaily

Build tiny machines. Share them with everyone.

A simple puzzle game about connecting blocks. No experience needed—a bit is just on or off (1 or 0).

  1. 1
    Pick a puzzle

    Start with a simple adding puzzle.

  2. 2
    Connect the blocks

    Add blocks, then link a green dot to a gray dot.

  3. 3
    Share and compare

    Get a checked score, then copy other people’s builds.

What are these blocks?
NOT-BOTH
A block that turns off only when both inputs are on. It is the only block you need.
MEMORY
A block that remembers one on/off value.
Bit
A bit is just on or off (1 or 0).
Start / answer
The values you start with and the answer you build.

Runs on the RAREXT protocol.
