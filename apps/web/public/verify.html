How can a web page be trusted to check anything?

It cannot, and it does not ask to be. The check is arithmetic: the page recomputes a cryptographic fingerprint from the copy's own contents and compares it with the one written down. You can read the algorithm in apps/web/src/verify.ts and the page logic in apps/web/src/verify-page.ts, run the same check with the command-line tools, or compare the numbers it shows with any other copy. If the page were lying, the numbers would not match anywhere else.
