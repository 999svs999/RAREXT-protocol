The honest definition

What “free” means here

The protocol does not bill you. That is a real property, and it is a narrow one. Here is exactly where it stops.

Writing, reading, verifying

No fee, no gate, no account. The reference registry is open source; run your own if you prefer ours.

One device, one copy

If your machine holds the bytes, it costs the protocol nothing — and it is a single copy. That is a backup that has not failed yet, not durability.

Durability is bought

More copies cost more disk somewhere. RAREXT makes the price explicit: k-of-n shards, published replica counts, retention challenges.

Physics still applies

Electricity, bandwidth, and the device are real costs. They are yours, and we do not pretend they vanished. Nothing here beats Shannon.

The commitment is forever. The bytes are rented. A publication's claim is permanent and recomputable; the storage that serves it is paid for by whoever chooses to hold it. When nobody does, the claim still verifies — you just have to supply the file.

The mechanics

Four steps, each one checkable

  1. 01

    Publish and sign

    Any file becomes a publication: a content hash, a kind, a meaning, and a signature from ECDSA-P256 or ML-DSA. The signing suite is recorded, so a reader knows what the proof is worth.

  2. 02

    Recompute, don't trust

    A deterministic verifier re-executes the claim. The shipped verifier runs unchanged in the browser and on the server and returns the same attestation from both.

  3. 03

    Anchor to a chain

    The Merkle root is anchored to a hash-linked log. The registry reads it back from an independent path before it says “confirmed” — a write is not a receipt.

  4. 04

    Replicate as shards

    Files are split into k-of-n Reed–Solomon shards in a content-addressed store. Lose holders up to n−k and any k rebuild the file; each shard's digest binds its index, parameters, and the payload it came from.

Truth over hype

Compression trades bytes for structure, fidelity, or compute. Erasure coding trades bytes for durability. Verification keeps both honest — and it only works if the claim says which trade it made.
